One line, 200 characters at most: the funniest excuse a robot vacuum can give for missing a spot.

## The line (121 characters)

> My sensors logged the dust under the sofa as a protected species, so I filed a preservation order and vacuumed around it.

The vacuum speaks for itself: deadpan, a little smug about its sensors, and
the dust under the sofa gets a preservation order instead of a cleaning.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
